# LC100 · 三版代码规范 v1

> **本项目以面试为导向。** 每道题在「三版代码」区提供可切换的三种形态,覆盖从刷题到笔试的全场景:

| 版本 | 场景 | 形态 |
| --- | --- | --- |
| ① **核心代码模式** | 提交 LeetCode / 白板讲思路 | 只有 `class Solution` 核心方法,平台喂参数、收返回值 |
| ② **面试版** | 面试手撕(飞书 / Coderpad) | 核心方法 + **内联示例调用**,写完直接 `python` 跑给面试官看 |
| ③ **机试版(ACM)** | 在线测评 / 华为机考 / 赛码笔试 | 自包含 + 自己读 `stdin` / 写 `stdout` |

三版从**同一份核心解法**拼出(DRY):面试版 = 核心 + 示例;机试版 = 核心 + IO 包装。

## 为什么这样分(调研依据)

- **面试主流看核心逻辑**:白板 / 飞书 / Coderpad 手撕,写核心函数、面试官口头喂例子 → ① 核心代码模式。
- **面试现场会"跑一下"**:写完自己造几个例子运行验证 → ② 面试版(可运行示例)。
- **部分环节才用 ACM**:在线测评、华为机考(牛客)、赛码笔试要求自己处理输入输出 → ③ 机试版。以华为(最典型最严格)为形态参考,做成**自包含**(不 import 任何私有模块)。

---

## 机试版(ACM)输入输出约定

平台输入都是**裸文本**(空格/换行分隔),自己 `split`/`map` 解析、`print` 输出;无 JSON / LeetCode 字面量风格。

### 输入(stdin)

| 数据类型 | 约定 | 示例 |
| --- | --- | --- |
| 一维数组 | 一行,空格分隔 | `2 7 11 15` |
| 标量(target / k …) | 单独一行 | `9` |
| 字符串 | 一行原样(允许空行) | `abcabcbb` |
| 字符串数组 | 第 1 行 `n`,随后 `n` 行各一个 | `3` / `abc` / `de` / `f` |
| 二维矩阵 | 第 1 行 `m n`,随后 `m` 行各 `n` 个 | `2 2` / `1 2` / `3 4` |
| 链表 | 一行,空格分隔节点值;空链表为空行 | `1 2 3 4 5` |
| 二叉树 | 一行层序遍历,空节点用 `null` | `3 9 20 null null 15 7` |
| 多参数 | 按上面规则**分行**,顺序见每题「标准输入」说明 | |

### 输出(stdout)

| 返回类型 | 约定 | 写法 |
| --- | --- | --- |
| 数组 | 一行空格分隔 | `print(*res)` |
| 标量 / 字符串 | 直接打印 | `print(res)` |
| 布尔 | **小写** `true` / `false`(贴 OJ) | `print("true" if res else "false")` |
| 二维 / 多行 | 逐行打印 | `for row in res: print(*row)` |

**默认单组输入**;每题「标准输入」说明里可附「多组到 EOF」提示(`for line in sys.stdin: ...`),供华为 / 阿里党套用。

## 数据与质量保证

- 三版源码统一由 `scripts/build_modes.py` 的 `MODES` 字典定义(每题写一次 core,自动拼三版)。
- 运行 `python3 scripts/build_modes.py` 即对所有题**回归自测**:
  - **核心版** → `ast` 语法检查
  - **面试版** → 无 stdin 跑,`stdout` 须等于 `demo_out`
  - **机试版** → `echo sample_in | python`,`stdout` 须等于 `sample_out`
  - 全部通过才写出 `data/modes.json`。
- `scripts/build.py` 再把 `modes` 注入每题 JSON;索引字段 `has_modes`。

### 字段结构(注入后的 `problem.modes`)

```json
{
  "core":      "class Solution: ...",
  "interview": "class Solution: ...\nif __name__ == \"__main__\": ...",
  "acm":       "class Solution: ...\ndef main(): ...",
  "acm_io": {
    "stdin": "...", "stdout": "...",
    "sample_in": "...", "sample_out": "..."
  }
}
```
